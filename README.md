# Jarvis Releases

Public release artifacts for the Jarvis desktop app.

This repo contains the signed installer and updater manifest (latest.json)
that the Tauri auto-updater polls. **No source code lives here** — see the
private NextDoorAI/jarvis2.0 repo for source.
